# Nemo iOS 🌊

A modern Japanese dictionary and learning application for iOS, built with SwiftUI, Apple Human Interface Guidelines, and native Liquid Glass design language.

Companion repository to [Nemo Android](https://github.com/AJAYAN14/Nemo).

---

## ✨ Features

- **主页便当盒 (Learning Dashboard Bento Grid)**: 
  - 打卡天数徽章与早中晚动态问候
  - 单词 / 语法模式平滑切换
  - 动态测量自适应高度平齐的环形学习进度指示器
  - 苹果官方原生 `.glassProminent` 原生液态玻璃 50pt 胶囊主行动按钮（深浅模式自适应、单词橙 / 语法绿）
- **进度仪表盘 (Progress Dashboard)**: 
  - 学习摘要 3 页 Bento 卡片轮播
  - 100% 对齐 Clash-Client 官方参数体系的高清列表行（29×29pt 连续圆角图标井、17pt/13pt 纯正字体层次与微米级分割线）
- **测试中心 (Testing Suite)**: 
  - 今日战报卡片、错题集、收藏夹
  - 单选测试、假名拼写与卡片连线
- **个人设置 (Settings & Personal)**: 
  - 账户同步、学习算法设置、TTS 发音人配置与实验室

---

## 🛠 运行与构建环境

- iOS 17.0+（iOS 26+ 原生支持系统级 `.glassProminent` 液态玻璃）
- Xcode 15.0+ / Xcode 16+
- Swift 5.9+

---

## 🚀 快速上手

1. 克隆代码库：
   ```bash
   git clone https://github.com/AJAYAN14/Nemo-iOS.git
   cd Nemo-iOS
   ```
2. 双击打开 `Nemo.xcodeproj`；
3. 选择你的 iPhone 真机或 iOS 模拟器；
4. 按下 `Cmd + R` 编译运行即可。
